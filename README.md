# System Info 📱

System Info is a modern Android application for viewing detailed information about your device and Android system.

## ✨ Features

- 🧠 CPU information
- 💾 RAM and storage usage
- 🔋 Detailed battery information
- 📱 Display information
- 🤖 Android and build information
- 🌡️ Thermal information
- 🌐 Network information
- 📡 Sensor information
- 🔎 Search system information
- 🔄 Refresh system information
- 📋 Copy system information
- 📤 Share a complete system report
- 🎨 Customizable themes
- ⚙️ Advanced information mode
- 💽 Binary and decimal storage units
- ⏱️ Configurable refresh interval
- ℹ️ Built-in About screen

## 🛠️ Built With

- Kotlin
- Jetpack Compose
- Material 3
- AndroidX
- DataStore Preferences
- Gradle Kotlin DSL

## 📱 Requirements

- Android 15 or newer
- Minimum SDK: 35
- Target SDK: 37
- Compile SDK: 37
